# Doorstep Repair Service - Website Frontend

Modern, high-performance React + Vite web application for Doorstep Repair Services (AC, Refrigerator, Washing Machine, Microwave Oven, TV, Geyser).

## Features
- **Appliance Directory**: AC, Refrigerator, Washing Machine, Geyser, Microwave, TV.
- **Doorstep Booking Engine**: Instant appointment scheduling with locality selection and express service dispatch.
- **Responsive Design**: Optimized for mobile, tablet, and desktop.
- **Lucide Iconography & Fast Asset Delivery**: High quality visual assets and fast loading times.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
